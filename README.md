# VK Music Recommendations

Исследование музыкальных рекомендаций
по пользовательскому намерению.

## Состав

- VK_Music_Recommendations_Final.ipynb — исследование и прототип
- data/ — данные, оценки и аудиоэмбеддинги

## Запуск в Google Colab

1. Загрузите ZIP в среду Colab.
2. Выполните в отдельной ячейке:
   !unzip -q VK_Music_Recommendations_Submission.zip -d /content
3. Откройте ноутбук из папки
   /content/VK_Music_Recommendations_Submission/
4. Выполняйте ячейки сверху вниз.

## Локальный запуск

Распакуйте ZIP и откройте ноутбук через Jupyter
из корневой папки проекта.

Для демонстрации рекомендаций нужен интернет:
модель LAION-CLAP загружается с Hugging Face.

## Данные и ограничения

80 композиций, 67 аудиоэмбеддингов CLAP.
Основной эксперимент: 5 запросов, 3 алгоритма.
Дополнительный эксперимент: 3 новых запроса.
Оценка релевантности: один слушатель.
