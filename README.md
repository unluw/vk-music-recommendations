# Разговорные рекомендации музыки по пользовательскому интенту

Рекомендательная система, которая подбирает музыкальные
композиции по текстовому описанию настроения, ситуации
или желаемой атмосферы прослушивания.

Проект выполнен в рамках тестового задания
Инженерно-математической школы НИУ ВШЭ × VK.

## Возможности системы

- Подбор музыки по запросам на естественном языке.
- Сопоставление текста и аудио с помощью модели CLAP.
- Ранжирование композиций по близости к запросу.
- Анализ настроения, контекста и атмосферы музыки.
- Сравнение нескольких рекомендательных подходов.
- Визуализация музыкальных характеристик и эмбеддингов.

## Данные и признаки

Сформирован каталог из **80 музыкальных композиций**.
Для **67 треков** обработаны аудиофрагменты.

Используемые характеристики:

- Музыкальные метаданные и жанры.
- Оценённый темп (BPM).
- Акустическая энергия (RMS).
- 512-мерные аудиоэмбеддинги CLAP.
- 18 семантических оценок CLAP, описывающих
  настроение, контекст прослушивания и атмосферу.

Происхождение данных описано в `DATASET_README.md`
и `metadata_provenance.csv`.

## Реализация

В проекте выполнены:

1. Подготовка музыкального каталога и проверка данных.
2. Анализ акустических и семантических характеристик.
3. Получение и исследование аудиоэмбеддингов CLAP.
4. Сравнение трёх подходов к музыкальным рекомендациям.
5. Оценка релевантности рекомендаций и NDCG@5.
6. Анализ повторяемости рекомендаций и ошибок подбора.
7. Проверка на дополнительных пользовательских запросах.
8. PCA и t-SNE визуализация эмбеддингов.
9. Демонстрация рекомендаций по текстовому запросу.

## Результаты экспериментов

На пяти пользовательских сценариях сравнивались:

- **CLAP** — прямое сопоставление текста и аудио.
- **Centered CLAP** — центрирование аудиоэмбеддингов.
- **Genre + BPM** — ранжирование по жанру и темпу.

Средняя ручная релевантность top-5 по шкале 0–3:

| Подход | Mean relevance@5 |
|---|---:|
| CLAP | 2.44 |
| Centered CLAP | 2.16 |
| Genre + BPM | 2.80 |

Исследование также включает сравнение NDCG@5,
анализ ошибок CLAP и разнообразия рекомендаций.

## Демонстрация

В финальном ноутбуке реализована функция
`recommend_music()`, которая принимает текстовое
описание желаемой музыки и возвращает ранжированный
список композиций.

Для демонстрации используются англоязычные запросы.
Например, можно попросить энергичную музыку
для тренировки или спокойную музыку для отдыха.

## Как запустить

1. Скачать репозиторий целиком.
2. Открыть `VK_Music_Recommendations_Final.ipynb`
   в Google Colab.
3. Сохранить папку `data` рядом с ноутбуком
   или разместить проект в
   `/content/VK_Music_Recommendations_Submission/`.
4. Выполнять ячейки последовательно сверху вниз.

Результаты аналитических ячеек уже сохранены
в ноутбуке и доступны для просмотра без запуска.

Для интерактивной демонстрации CLAP потребуется
подключение к интернету для загрузки модели
с Hugging Face. GPU желателен, но не обязателен.

## Ограничения и перспективы

Результаты получены на небольшом каталоге.
Ручная оценка проводилась одним слушателем,
а правила жанрового ранжирования настраивались
под тестовые сценарии.

Архитектура позволяет расширять каталог,
добавлять музыкальные признаки и исследовать
гибридные методы ранжирования.
