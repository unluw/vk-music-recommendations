# Задание 1. Сбор музыкального датасета

## Цель
Собрать каталог из 50–100 музыкальных композиций для исследования
разговорных рекомендаций по пользовательскому интенту.

Итоговый датасет содержит 80 треков:
40 из российского чарта и 40 из международной подборки.

## Источники данных

1. ArtistLab (https://artistlab.ru/chart) — российский чарт
   от 20 октября 2026 года. Исходная выборка — 100 позиций.

2. iTunes Search API — поиск композиций по исполнителям,
   получение жанров, дат релиза, ссылок Apple Music
   и доступных аудиопревью.

3. iTunes Lookup API — получение аудиопревью международных
   композиций по идентификаторам Apple Music.

4. MusicBrainz — дополнительная проверка отдельных метаданных,
   в частности года выпуска композиции «ДИНАСТИЯ».

## Критерии отбора

Российская часть: 40 композиций из чарта ArtistLab,
позиции 1–42 за исключением 16 и 29.
Обе исключённые композиции включали исполнителя madk1d.
Первоначальная причина их исключения не зафиксирована.

Международная часть: 40 композиций из предварительно
собранного пула iTunes, с учётом жанрового разнообразия.

## Жанровое распределение

| Жанр | Треков |
|---|---:|
| Pop | 25 |
| Hip-Hop/Rap | 14 |
| Electronic | 12 |
| Alternative/Indie | 10 |
| R&B/Soul | 4 |
| Country | 1 |
| Rock | 1 |
| Unknown | 13 |
| **Всего** | **80** |

Unknown обозначает отсутствие подтверждённых жанровых
метаданных, а не самостоятельный музыкальный жанр.

Строгих квот по жанрам не устанавливалось.

## Ограничения по исполнителям

При отборе стремились избегать избыточного повторения
исполнителей.

При подсчёте отдельных участников коллабораций
максимальное количество композиций на одного артиста — 4.

Исключения из ориентировочного лимита в 2 трека:
- madk1d — 4 композиции;
- VILLIAN — 3 композиции.

Остальные участники представлены не более чем
в двух композициях.

## Структура датасета

Основной файл: music_dataset_final_candidate.csv

80 строк и 17 столбцов.

Ключевые поля:
- song_id — идентификатор композиции;
- artist — исполнитель;
- title — название;
- genre и genre_group — жанровые характеристики;
- release_year — год выпуска;
- track_url — ссылка на страницу трека;
- preview_url — ссылка на аудиофрагмент;
- has_audio_preview — результат проверки доступности превью;
- selection_group — группа отбора.

## Проверка качества

- 80 треков;
- 0 дубликатов song_id;
- 0 дубликатов пары исполнитель + название;
- 0 пропусков исполнителя и названия;
- 67 проверенных аудиопревью;
- 13 записей без аудиопревью;
- 13 записей без жанра;
- 12 записей без года выпуска.

Аудиоссылки проверялись HTTP-запросами с частичной
загрузкой данных. Полное декодирование аудио
на этом этапе не проводилось.

## Ограничения

Датасет не является репрезентативной выборкой
всей современной музыки.

Жанровое распределение неравномерно.
Часть метаданных отсутствует.
Доступность внешних аудиоссылок может меняться.

Для дальнейшего извлечения аудиопризнаков доступны
67 предварительно проверенных аудиофрагментов.
